# Amazon Financial Performance Analysis
Financial performance analysis of Amazon (2024–2025) using PostgreSQL, SQL and Tableau.

## Interactive Tableau Dashboard

Explore the interactive dashboard on Tableau Public:

[View Amazon Financial Performance Dashboard](https://public.tableau.com/app/profile/jamila.gasimova/viz/Amazon_Financial_Dashboard_2024_2025/AMAZONFINANCIALPERFORMANCEDASHBOARD)

The dashboard includes:
- Total Revenue and AWS Revenue KPIs
- Year-over-Year Revenue Growth
- Revenue by Business Segment
- Revenue Share by Business Segment
- Revenue Comparison: 2024 vs 2025
- Interactive Year Filter
